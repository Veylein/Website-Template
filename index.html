Legend / Cheat Sheet

  • .hero → Full-screen background section
  • .hero-overlay → Overlay for hero text readability
  • .navbar → Top navigation bar
  • .card → Content container card
  • .card.glass → Blurry glass card
  • .btn → Button-style link
  • .alert → Info / success / danger alert
  • .badge → Small status label
  • .tooltip → Hover hint
  • .dropdown → Hover-based menu
  • .modal → Popup modal
